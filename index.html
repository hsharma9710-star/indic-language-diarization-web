Language diarization: English + Indian languages

Name the languages if you know them (more accurate). Leave both on auto to detect them.

This model finds the languages by itself (English, Hindi, Kannada, Malayalam, Tamil, Telugu, Assamese, Bengali, Marathi, Odia). It is large: the first use downloads about 560 MB (cached afterwards) and every 30 s of audio takes 1–2 minutes to analyse on a normal laptop, so this tab accepts up to 3 minutes and a short clip is the best way to try it. Model and method: github.com/MohitAiry/Whisper-Linear-LD.

If the file holds several recordings, pick the one that belongs to this audio. You can load the reference before or after diarizing.

Research prototype. Our model is trained on synthetic code-switched speech: on real conversations about one 200 ms bin in four is wrong when the
  languages are named, and automatic language detection is less reliable (it often adds a similar-sounding second language).
  The English check (on by default) finds most of the English in Hindi news with Indian-accented English, but some is still missed.
  First use downloads the 137 MB model plus 72 MB for the English check (cached afterwards). Whisper-Linear-LD is a separate model by Mohit; it is run here as an
  8-bit quantised copy of the encoder, so its results can differ slightly from the original GPU code. The DER is computed with a port of the NIST scorer (dscore).
  Code, method and results: github.com/hsharma9710-star/indic-language-diarization.
